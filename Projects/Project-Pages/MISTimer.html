Parameterizeable TPU in Chisel

When taking UCSC's VLSI Research course I worked with a partner to develop an EDA tool to measure the effect of Multiple Input Switching on OpenROAD subcircuits.

Multiple Input Switching (MIS) is a phenomenon where multiple inputs of a gate switch simultaneously, a case which is not normally simulated when performing static timing analysis. Instead, modern timing tools assume some margin of error to account for the possible worst case scenario, however the degree of this margin is hardware analagous and often overly pessimistic, leading to unnecessarily slower designs.

The reason MIS affects timing is that when series inputs switch simultaneously, the resistance incurred when both transistors saturate is greater than the SIS case where the resistance is equivalent to a single transistor resulting in a longer delay. The inverse is true for parallel networks, where transistors switching simultaneously results in a lower resistance and a shorter delay.

Our tool uses SPICE to force the MIS case at each stage of each critical path, accumulating both the worst case speed up and slow down at the output. Our results show that the actual worst case MIS effects on subcircuits is 5x less extreme than OpenROAD's default margins. Integrating our tool into the OpenROAD flow would allow for more accurate timing analysis and faster designs overall.

Pipeline Overview

  1. Opens subcircuit.sp and preprocesses for compatibility
  2. Identifies first stage with subcircuits and trims the subsequent stages
  3. Measures unmodified SIS delay to beginning of stage
  4. Adds pwl to side input at the measured arrival time
  5. Saves modified script if slower or faster than worst cases
  6. Repeats for all subsequent stages
