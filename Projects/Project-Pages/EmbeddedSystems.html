Fullstack GPS to Maps Integration via Microcontroller

Davis Eats (Embedded Systems)


Davis Eats is a system programmed in C using Code Composer Studio and developed on a Texas Instruments CC3200 microcontroller. It interfaces with GPS by reading NMEA sentences from an antennae, and receives user input via an infrared sensor and remote control. The system then encodes the users location and choice of restaurant into a JSON object which is sent to a webhook server via HTTP POST. The resulting directions are emailed to the user. This full stack integration was a great learning experience in embedded systems and web development.
