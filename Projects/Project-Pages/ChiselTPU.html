Parameterizeable TPU in Chisel

When taking UCSC's Agile Hardware Design course I revisited my TPU project, re-implementing it in Chisel (an HDL embedded in Scala). Together with a classmate we turned the fixed-size, fixed-width design into a fully parameterised core.

TPU Top Level Architecture


Our iterative milestones were:

  1. Prototype a single MAC (multiply-accumulate) and validate its output.
  2. Wire 4 MACs into a fixed 2 x 2 systolic array; hard-code inputs and validation.
  3. Add top-level TPU control logic (what data and when to input).
  4. Parameterize I/O so the array accepts vectors and returns a matrix.
  5. Generate arbitrary-size systolic array sizes from parameters.
  6. Adapt the controller for variable-sized input matrices.
  7. Add sparse-aware write logic to skip zeroes and save bandwidth.
  8. Pad non-square inputs with zeros automatically for full compatible MM.
  9. Implement tiling to process large matrices on smaller arrays.
  10. Add a convolution mode by rewiring the controller's addressing scheme.


Parameterized Components via Chisel

- Input bitwidth
- MAC/output bitwidth
- Systolic array width
- Mode: Convolution or Matrix Multiplication
- Mode: Sparse or Dense



Future work

- Explore hardware optimizations for specific workloads, such as CNNs or RNNs.
- Properly exploit sparse workloads in the form of detecting cycles with all zero inputs.
